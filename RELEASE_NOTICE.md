# Anonymous Release Notice

This repository is being prepared as an anonymous reviewer artifact for an
ICLR submission. It is not yet the final public software release.

The artifact intentionally omits a public software-license grant, author
identities, raw datasets, third-party weights, private logs, and credentials.
Before a public release, the authors must select a software license, create a
named `CITATION.cff`, audit all third-party code/data/model terms, and publish
the final data and checkpoint availability matrix. Do not infer a license or a
redistribution permission from the anonymous review artifact.
