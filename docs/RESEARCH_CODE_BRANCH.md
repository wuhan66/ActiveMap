# Private Research-Code Branch

`research-code-full-20260904` is an archival branch for the complete ActiveMap
research implementation. It contains all in-tree source, experiment scripts,
tests, configuration files, schemas, examples, tools, and environment
definitions available in the development workspace at the time of the branch.

It intentionally excludes raw and derived data, checkpoints, experiment logs,
model outputs, caches, archives, credentials, and third-party repository
clones. This keeps the branch suitable for a private GitHub backup while
preserving the clean, shareable release boundary on `main`.
